# Almaz Birthday Bot — текстовая версия

Бот каждый день запускается через GitHub Actions, проверяет `birthdays.csv` и отправляет в Telegram юморное футбольно-футзальное поздравление на русском языке.

Поздравления лежат в `congratulations.txt`. Сейчас там 100 вариантов.

`used_congratulations.json` хранит историю использованных поздравлений. Благодаря этому поздравления не повторяются, пока не закончатся все 100 вариантов.

## Секреты GitHub

- `BOT_TOKEN`
- `CHAT_ID`
